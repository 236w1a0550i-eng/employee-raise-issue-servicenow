# Employee Raise Issue – ServiceNow

## Project Overview

The **Employee Raise Issue** application is a custom ServiceNow application designed to allow employees to raise and track issues easily through the Service Portal.

The application uses a **Record Producer** to provide a user-friendly form for submitting employee issues. Submitted requests are stored in a custom table and can be managed by the appropriate support team.

## Key Features

- Custom ServiceNow application
- Employee issue submission using Record Producer
- Service Portal integration
- Custom table for storing employee issues
- User-friendly issue submission form
- Issue tracking and management
- Automated workflow for handling submitted issues

## Technologies Used

- ServiceNow
- Service Portal
- Record Producer
- Custom Tables
- Client Scripts
- UI Policies
- Business Rules
- Workflows

## Purpose

The main purpose of this project is to provide employees with a simple and efficient way to raise issues while allowing support teams to manage and track those issues within ServiceNow.
